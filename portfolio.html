C++ · Object-oriented design01

Banking System

A learning project concept for organizing account operations around clear object responsibilities and a simple transaction history.

  • Account and transaction modeling
  • Encapsulated operations
  • Stack-based history concept
View project concept

The design separates account state from transaction handling. A stack can keep the most recent operations accessible for a simple history view.

struct Transaction {
    std::string type;
    double amount;
};

class Account {
public:
    bool deposit(double amount);
    bool withdraw(double amount);
private:
    double balance{0.0};
    std::stack<Transaction> history;
};

C++ · Data organization02

Inventory Management System

A modular system concept for keeping product records organized and making stock changes easier to track.

  • Product records and categories
  • Stock updates and low-stock checks
  • Clear, maintainable module structure
View project concept

Possible modules include product data, inventory operations, and a menu-driven interface. Separating these concerns keeps the core logic easier to test and extend.

Example workflow: add an item → receive stock → record a sale → review available quantity.
