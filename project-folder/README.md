# Alexandria Archive & Learning Hub

A single-page, English-language HTML5 project demonstrating semantic structure, keyboard-accessible navigation, native form validation, a membership data table, and an audio player without CSS or JavaScript frameworks.

## Files

- `index.html` — the complete library and research archive page.

## Run

Open `index.html` in a modern browser. The Unsplash book images and public-domain audio preview are loaded from their respective hosts. The example form uses the visitor's default email application; a production deployment should connect it to a secure, accessible server-side form handler.
